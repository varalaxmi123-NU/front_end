# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :x:                |

## Reporting a Vulnerability

PULSE 30 runs 100% client-side with zero external telemetry transmission. If you discover a security vulnerability or sensitive data leak:
1. Please do not open a public issue.
2. Email `varalaxminu@gmail.com` with reproducible steps and proof-of-concept details.
3. We will respond within 48 hours to confirm the vulnerability and provide a fix.
